# 🔄 ReCircuit – Second-Hand Electronics Marketplace

ReCircuit is a web-based marketplace designed to promote the reuse and resale of electronic devices. It connects buyers and sellers, making pre-owned electronics more accessible and affordable while reducing electronic waste.

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

### ✨ Key Features
- Responsive user interface
- Product listings and categories
- Search functionality
- Featured product cards

### 🎯 Goal
Encouraging sustainable technology consumption through affordable electronics and a circular economy.
